## 加载与界面

- [ ] 退出旧 D4KeyHelp 和旧扩展进程。
- [ ] Windows Git Bash 执行 `bash app/ahk/tests/run.sh validate`，确认主程序和测试可加载。
- [ ] 执行 `bash app/ahk/tests/run.sh smoke`，检查结果，不只依赖 AHK 进程退出码。
- [ ] PowerShell 启动器正确找到 AHK v2，含空格路径也能启动。
- [ ] 只有一个 d4box 窗口，四组预设、主题和语言切换可用。
- [ ] 配置保存、重启恢复、日志开关与轮转正常，Git 工作区不出现个人设置。

## 已迁入功能

- [ ] F1 启停、切出游戏暂停、返回恢复、手动点击暂停正常。

## 窗口诊断

- [ ] 前台游戏按 Ctrl+Alt+F8 显示客户区坐标和尺寸，约 5 秒后提示消失。
- [ ] 日志在 `app/ahk/.runtime/window-diagnostics.log`，切出游戏后热键不触发。
- [ ] 分别记录 1080p、1440p、4K、DPI 缩放、窗口模式和多显示器表现。
- [ ] 诊断本身不发送游戏按键、不点击、不滚动。

- [ ] `bash app/ahk/tests/run.sh workflow` 通过规划、存储、取消与检查失败的模拟测试。

- [ ] 内置流程不可覆盖；升级黄装只影响内置流程；中文配置重启后保持完整。
- [ ] 普通红装和黄装实际操作顺序与原版一致，尤其核对 0.380 / 0.350 的配方位置。

- [ ] 失焦、移动窗口、超时、连续 F3 取消都不会产生后续点击或重入；战斗宏不抢输入。
