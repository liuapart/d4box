# Windows 验证清单

状态：初始化阶段，以下项目均待真实 Windows 环境验证。Mac 的项目检查不覆盖这些项目。

## 启动

- [ ] AutoHotkey v2 路径被正确检测，显式 `-AhkPath` 也可使用。
- [ ] 启动器可在含空格的项目路径下启动两个脚本。
- [ ] `-SkipUpstream` 只启动扩展。
- [ ] 上游界面正常启动，扩展没有修改其文件、设置或宏状态。
- [ ] 各程序都能通过各自托盘菜单退出。

## 窗口诊断

- [ ] 游戏前台按 Ctrl+Alt+F8，显示窗口客户区坐标和尺寸。
- [ ] `.runtime/window-diagnostics.log` 有对应记录，提示约 5 秒后消失。
- [ ] 切出游戏后，同一热键不会触发诊断。
- [ ] 记录 1080p、1440p、4K 的实际结果与游戏显示模式。
- [ ] 记录 Windows 100%、125%、150% DPI 缩放结果。
- [ ] 验证窗口移动、无边框模式及不同显示器上的坐标。
- [ ] 全程没有新增自动点击、滚动或游戏按键输入。

## 验证记录

每次记录主仓库提交、submodule 提交、Windows 与 AHK 版本、分辨率、DPI、游戏 UI 缩放、显示模式，以及通过/失败和相关日志。后续截图坐标是否与客户区坐标一致，需要单独验证，不能根据本诊断直接认定。
